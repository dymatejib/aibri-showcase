# НЕОБЯЗАТЕЛЬНЫЙ слой: бесплатное локальное распознавание фотографий.
#
# Это macOS Vision через пакет `ocrmac` — на Linux и Windows такого API нет, поэтому
# маркер `sys_platform` честно отсекает установку вместо непонятной ошибки сборки.
# Ставить отдельно и осознанно:
#
#     pip install -r requirements-ocr.txt
#
# Что меняется от установки: тесты фото-пути (tests/test_photo_ocr.py) перестают
# пропускаться и начинают гонять настоящий OCR по JPEG-ам из fixtures/photos/.
# Что НЕ меняется: текстовый разбор накладных и Z-отчётов, деньги, стражи —
# они не знают про этот пакет вовсе.
#
# `ocrmac` тянет за собой Pillow и pyobjc-framework-Vision. На Linux/Windows Pillow
# можно поставить отдельно (`pip install pillow`) — тогда кросс-ОС проверка целостности
# фотографий пройдёт ещё и через PIL; без него она идёт по заголовку JPEG стандартной
# библиотекой.
ocrmac>=0.3; sys_platform == "darwin"
